# 読み

解読したままの綴りに、語の区切りだけを入れた。[ ] は表の外の組か崩れた字で、→ の右は読み替えの案（`docs/OPEN.md`）。й は и、ё は е で書かれ、二重の н は1つで書かれることがある（ревизионая、совершено）。

## Nr 451（M316 roll 43、コマ 0427・0428。1921年5月30日付け、6月14日の再送。末尾 KRASSIN）

> работа берлинского то[ф]гого представительства развивается вполне нормально. от все[м] деловых кругов получаю самые лестные отзывы. аусвэртигес амт также констатирует благоприятное изменение общеи атмосферы торгового представительства. из разговоров лутовиновым стомоняковым заключаю, что ревизионая [28]ия [14]ала бога[]ыи материал, весьма невыгодно характеризующи предыдущи период берлинского представительства. [77]отают, лошади, чем задерживается окончание. убедительнеише прошу, как можно скореэ высл[50]ть берлин т. кулябко, помощь которого в работе ревизионо[з] [28]ии совершено необходима. визу, согласно договора, должен дать штелер, на чем прошу настоять. ни в каком случае не предпринимаите никаких решении ли мер не подождав до[54]лада ревизионо[н] [28]ии. иначе спутаете всю ея [77]оту, облегчите заметание следов. лутовинов стомоняков по окончании ревизии явятся для личного доклада [91]к москву

読み替えの案：то[ф]гого → торгового、все[м] → всех、[28] → комисс（ревизионная комиссия）、[14]ала → дала、бога[]ыи → богатыи、[77] → раб（работают、работу）、высл[50]ть → выслать、до[54]лада → доклада、[91]к → ЦК。

## Nr 523（コマ 0432。1921年6月14日付け。末尾 LUTOWINOFF）

> вашэ письмо [16] июня получил. опре[о]эленоэ вами п[д]ложениэ коппа берлинэ нахожу абсолютно недопустимым. копп заявил, что наркоминдэл уже рэшил оставить эго берлине полпрэдом. эсли это так категоричэски протестую против его назначения до окон[ю]ания ревизии, а такжэ требую срочного указания ко[у]у сдать дела. черэз [76][53][18] часов сдаю бродовскому [?0]

読み替えの案：опре[о]эленоэ → опредэленоэ（определенное）、п[д]ложениэ → положениэ、окон[ю]ания → окончания、ко[у]у → кому。[16] と [76][53][18] は数とみられる（値は不明）。

人名と語：Красин（Krassin）、Лутовинов（Lutowinoff）、Стомоняков、Кулябко、Копп、Бродовский、Штелер（モスクワのドイツ代表 Stähler）、аусвэртигес амт（Auswärtiges Amt）、наркоминдел（外務人民委員部）、полпред（全権代表）。
