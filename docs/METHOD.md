# 方法

## 1. 書き起こし
- 1回目：NARA の目録が出す OCR（M316 roll 43）から、5桁の群を取り出した（タイプライターに数字の 1 が無く、大文字の I で打たれているので 1 に直した）。
- コマ 0428 の頭の「/21545/」は、コマ 0427 の最後の群の繰り返し（ページのつなぎ）なので除いた。これで Nr 451 は 1,600桁になる。
- 画像を見て直したのは1桁だけ：コマ 0427 の12行目2群目の頭の桁（上に「I」が打ち込まれている。0 → 1）。
- 2回目（独立の読み）：コマの本文を7行ずつの帯に切った画像8枚（長い辺 2,000px）を、OpenAI Codex に1枚ずつ、空のフォルダから渡した。渡したのは画像と依頼文（`second/PROMPT.md`）だけで、1回目の読み・表・平文は渡していない。実行記録は、8回とも返答1件だけで、コマンドの実行はなかった。結果は `second/codex/`。
- 比べ方：数字の群だけを取り出し、迷いの書き方 {a/b} は最初の候補を採って、桁の並びを突き合わせた。Nr 451 は 1,600桁のうち 1,598桁が一致（99.88%）、Nr 523 は 575桁が全部一致。
  - 食い違い1：コマ 0427 の5行目2群目の2桁目。紙の上で打ち直しが重なっていて、OCR は 5、Codex は 0（または 9）と読んだ。平文からは 7（выслать の а）が合う。データは 5 のままにし、この組は「通らない」に数えた。
  - 食い違い2：コマ 0427 の群 00668。画像は 00668 で、Codex が1桁落としていた。
- **人は画像と書き起こしを照らしていない。**

## 1a. そろった桁の抜き取り（画像での2択）
- 2回の読みがそろった桁から、電報ごとに 90桁を無作為に抜いた（Nr 451 は食い違いの2桁と画像で直した1桁を除く）。うち 10桁は、判定役が画像を見ているかを確かめる問いとして先に指定した。
- 各桁について、その桁を含む群の切り出しを見せ、「書き起こしの桁」と「よく取り違える桁」（0↔6・9、1↔7・4、3↔8・5 など）の2択で答えさせた。並びは無作為で、どちらが書き起こしかは伏せた。判定役は OpenAI Codex（gpt-6-astra、推論の深さ high、画像10問ずつ18枚を1枚ずつ）と Claude Sonnet（同じ18枚）。依頼文の例は `second/PROMPT_judge.md`、問いと答えは `second/judgements.tsv`。
- 結果：Nr 451・Nr 523 とも、Codex・Sonnet の両方が 90問すべてで書き起こしの桁を選んだ（80/80 と 10/10）。直した桁はない。
- 2択の問いなので、「仕込みの誤り」は、誤った桁を選択肢に入れることでしか作れない。10問の確かめは、形の上ではほかの 80問と同じである。

## 2. 方式の割り出し
- 数字の群の前に、ロシア語の数の語がある（SOROK＝40、DWADZAT TCHETYRE＝24）。桁数は 1,600＝40×40、575≒24×24。
- 桁をその数ずつに切ると、高い数字（6〜9）だけの列と低い数字（1〜5）だけの列が交互に並ぶ。0 を除いた桁のうち、この型に合うのは Nr 451 で 1,232 のうち 1,169（94.9%）、Nr 523 で 468 のうち 445（95.1%）。合わない桁は、表の外の組（10・33・28 など）と誤りである。
- 隣り合う2列を行ごとに組にすると、組の種類は約30（Nr 451 は 37種、Nr 523 は 34種）、一致指数は 0.0551 と 0.0490 で、1字＝1組の換字に合う。
- 読む向き：Nr 451 の正方形は、39行目の右端の4組だけに字があり、その左と40行目は 00 で埋まっている。文の終わりが右端にあるので、行は右から左へ読む。Nr 523 は列の順（2桁目の列が先）も行の向きも逆である。
- 列の入れ替えがないことは、同じ長い並び（14組の「представите…」など）が、行の中の違う位置に何度も出ることから分かる。

## 3. 表の復元
- Nr 451 の 764組だけを使い、よく出る 32種の組に 32字のロシア語の字を1対1で割り当てる焼きなまし（ロシア語の4字組の点）を3回走らせた。3回とも同じ点に収まり、文が読めた。平文の手がかり（crib）は使っていない。
- 焼きなましの後に、文を読んで直した値は3つ：10（ф → ピリオド）、33（й → コンマ）、71（ъ → ф。атмосферы）。28 は ц が割り当てられていたが、3回とも「ревизионая [28]ия」の形で出るので表から外し、未解決に回した。
- Nr 523 には、この表をそのまま当てた。Nr 523 は表を作るのに使っていない。

## 4. 対照
- `src/control.py`：表の字の値（30字）をかき混ぜた表を 1,000 個作り、同じ暗号文を復号して、ロシア語の4字組の点（wordfreq の上位5万語から作った表、1字あたりの平均）を比べた。本物以上になったのは、Nr 451・Nr 523 とも 0 回（本物 −11.127・−12.329、かき混ぜの最高 −14.686・−14.796）。
- 同じ表で行を逆向きに読むと −13.889・−14.282 で、かき混ぜた表に近い。
- Nr 523 は表作りに使っていないので、Nr 523 が同じ表で読めることは、表の独立した確かめになる。

## 5. 「語として通る組」の数え方
- 読む順に並べた組（末尾の 00 を除く）を1つずつ、「表の値で読め、語の一部として通る」かどうかで分けた（`data/reading_*.tsv` の status）。
- 通らない方に数えたもの：表の外の組（文脈から値を推定したものも含む）、1字崩れた語の崩れた字、打ち直しで読めない桁を含む組、桁の足りない最後の組。
- Nr 451：764組のうち通らない 14、通る 750（98.2%）。Nr 523：288組のうち通らない 9、通る 279（96.9%）。
- 語の区切りと句読点の解釈は読み手が入れた。前置詞のない電報文なので、格の読み方には幅がある。

## 6. 較正
当時の解読や刊本の文面は見当たらないので、答えを見ない較正はできていない（`docs/PRIOR_CHECK.md`）。

## 7. 限界
- 書き起こしは OCR と AI によるもので、人は確かめていない。
- 表の外の組の値（комисс、раб、ц）は文脈からの推定で、数の組は読めていない。
- 人名の同定（Кулябко、Бродовский、Штелер）と日付・経緯の解釈は、この2通の文面だけからのもので、ほかの史料とは照らしていない。
