# ソ連の無線電報 Nr 451（Krassin）と Nr 523（Lutowinoff）、1921年：方式・表・読み

米国国立公文書館（NARA）RG 59、861.00（マイクロフィルム M316 roll 43）にある、1921年6月にコンスタンティノープルの米国高等弁務官府が傍受したベルリン→モスクワの数字の無線電報2通（コマ 0427・0428 と 0432）について、暗号の方式と表を暗号文だけから戻し、2通とも読んだ記録である。資料は Cyphersolver 台帳の目録 669「Soviet and German cipher radiograms of 1921」に含まれる。

**先行との関係。** 2026年11月10日時点で、`docs/PRIOR_CHECK.md` に挙げた先では、この2通の解読も平文も見当たらない。同じ綴りについては Cyphersolver が、字の転置の電報2通（Lejava Nr 1196、Voikov Nr 1883）を解読し、数字の電報は「値が1つも分からない」として作業を公開している（targets/kopp1921 ほか）。ここで読んだ2通は、その記録に出てこない。

**状態：全文の読み（2通とも）。** 語として通る組は Nr 451 が 764組のうち 750（98.2%）、Nr 523 が 288組のうち 279（96.9%）。残りは、表の外の組（数・略語とみられる 9種）と、1字崩れた語である（`docs/OPEN.md`）。

**人は書き起こしを確かめていない。** 書き起こしは NARA の OCR をもとに AI が作り、別の AI が画像から独立に読んだものと比べた。AI どうしの一致は、人の確認の代わりにならない。

## 読めたこと

Nr 451（1921年5月30日付け、6月14日の再送。Krassin から Chicherin へ）：

> ベルリン通商代表部の仕事はまったく順調に進んでいる。実業界のどこからも非常に良い評判を聞く。ドイツ外務省（Auswärtiges Amt）も、通商代表部をめぐる雰囲気の好転を認めている。Lutovinov・Stomonyakov との話から、査察委員会は、ベルリン代表部の前の時期をきわめて不利に示す豊富な材料を出したと判断する。馬のように働いていて、そのために終わりが遅れている。同志 Kulyabko をできるだけ早くベルリンへ送ってほしい。査察委員会の仕事に彼の助けがどうしても要る。査証は協定に従い Stähler が出すべきで、これを強く求めてほしい。査察委員会の報告を待たずに、どんな決定も措置もとらないでほしい。さもないと、その仕事をすべて混乱させ、痕跡を消すのを助けることになる。Lutovinov と Stomonyakov は査察が終わりしだい、報告のためモスクワへ行く。

Nr 523（1921年6月14日付け。Lutowinoff から Chicherin へ、Litvinov 宛て。写し Chicherin・Molotov・Shlyapnikov）：

> […] 日付の貴信を受け取った。あなたが定めた Kopp のベルリンでの地位は、絶対に容認できない。Kopp は、外務人民委員部が彼を全権代表としてベルリンに残すことを既に決めたと言っている。そうであれば、査察が終わる前の任命に断固として抗議し、誰に事務を引き継ぐかの至急の指示を求める。[…] 時間後に Brodovsky に引き継ぐ。

ロシア語の本文（解読したままの綴り）と英訳は `docs/READING.md`、組ごとの読みは `data/reading_451.tsv`・`data/reading_523.tsv`。

## 方式と表

1. 平文（ロシア語。前置詞を落とした電報文で、й は и、ё は е と書く）の1字を、5×6 の表で2桁にする。1桁目は 6・7・8・9・0、2桁目は 0〜5。
2. 一辺 N 桁の正方形に、1行に N/2 字ずつ書く。N は、数字の群の前にロシア語で綴られる（SOROK＝40、DWADZAT TCHETYRE＝24）。余りは 00 で埋める。
3. 正方形を列ごとに上から下へ、端の列から順に送る（列の入れ替えはない）。

```
     0  1  2  3  4  5
6    е  в  ь  э  к  щ
7    а  ф  я  з  н  р
8    б  ы  г  л  ч  ю
9    ж  ·  ш  и  д  о
0    ·  т  п  х  у  м        06＝с   10＝ピリオド   33＝コンマ   00＝詰め物
```

Nr 451 では、1桁目の列・2桁目の列の順に並び、行は**右から左**へ読む。Nr 523 は鏡写しで、2桁目の列・1桁目の列の順に並び、行は左から右へ読む。受信した数字を N 桁ずつに切ると、高い数字（6〜9）の列と低い数字（1〜5）の列が交互に並ぶので、方式はそこから分かる。

復号：`python3 src/decrypt.py`。テスト：`python3 -m unittest discover -s tests`。対照：`python3 src/control.py`（`wordfreq` が要る）。

## AI の使用

資料の選別・方式の割り出し・表の復元・読み・文書は Claude Fable 5.2（Anthropic）。書き起こしのもとは NARA の目録が出す OCR。2回目の書き起こしは OpenAI Codex（codex-cli 0.163.0-alpha.10.2、gpt-6-astra、推論の深さ high）。画像での2択の判定は同じ Codex と Claude Sonnet。先行の確かめは Claude Fable 5.2 と、読みを作っていない別の読み手（Claude Sonnet）。人が行ったのは、作業の指示と公開の判断である。人は画像と書き起こし・読みを照らしていない。
